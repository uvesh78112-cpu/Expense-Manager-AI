# Expense Manager AI 🛡️

A high-performance, secure Flutter application designed for smart expense tracking and financial privacy.

## 🚀 Key Features
- **AI-Powered Scanning:** Integrated with Google ML Kit for on-device OCR.
- **Privacy-First:** Zero-cloud architecture—all data stays on your device.
- **Medical ID Tracking:** Specialized detection for medical bills and healthcare documentation.
- **Secure Storage:** Local encryption for all financial records.

## 🛠️ Tech Stack
- **Framework:** Flutter / Dart
- **AI Engine:** Google ML Kit
- **Local Storage:** Hive / SQLite
